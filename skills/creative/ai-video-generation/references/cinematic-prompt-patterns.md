# Cinematic AI Video Prompt Patterns

## Prompt Structure Formula

```
[Camera movement] + [Subject description] + [Action] + [Setting/Environment] + [Lighting] + [Mood/Atmosphere] + [Style modifiers]
```

## Camera Movements
- `Cinematic aerial drone shot` — establishing shots, landscapes
- `Slow tracking shot` — following a character
- `Close-up portrait` — emotional moments, faces
- `Wide cinematic shot` — epic scale, environments
- `Low angle dramatic shot` — power, divine, supernatural
- `Slow motion` — emotional climax moments
- `Dolly zoom` — revelation, shock moments

## Lighting Keywords
- `golden hour` — warm, nostalgic, tender scenes
- `dramatic backlight` — silhouettes, farewells
- `dark moody lighting` — conflict, tension
- `storm clouds gathering` — supernatural, divine wrath
- `sunrise golden light` — hope, new beginnings, epilogues

## Style Modifiers (always append)
- `photorealistic, 4K cinematic quality` — base quality
- `shallow depth of field` — emotional close-ups
- `epic scale` — wide establishing shots
- `deeply emotional` — character moments

## Negative Prompts (use on all platforms that support it)
```
cartoon, anime, 3D render, low quality, blurry, deformed, watermark, text overlay, split screen
```

## Character Consistency Tips
1. Generate a reference image of each character first (via Midjourney/DALL-E/Flux)
2. Use "Character Reference" feature on PixVerse or "Characters" on Runway
3. Include consistent clothing/appearance descriptions in every prompt
4. Vidu AI's multi-reference feature (up to 7 refs) is best for maintaining identity

## Scene Type → Platform Recommendation
| Scene Type | Best Platform | Why |
|-----------|--------------|-----|
| Facial close-ups | Kling AI | Best facial realism |
| Body movement/action | Hailuo AI | Most natural motion |
| Multi-shot narrative | PixVerse | Panel/multi-shot features |
| Character consistency | Vidu AI | Multi-reference binding |
| Highest quality single shot | Runway Gen-4 | Industry-leading quality |
| Supernatural/VFX scenes | PixVerse or Kling | Good at dramatic effects |
