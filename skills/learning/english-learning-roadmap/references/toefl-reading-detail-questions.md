# TOEFL Reading: Stated Detail Questions (Skill 3)

Pattern reference for detail-level TOEFL reading questions. Complements gist/focus (Skill 1) in main `toefl-reading-comprehension.md`.

## Question Patterns

- "According to the passage, what/when/where/who..."
- "The passage indicates that..."
- "The passage states that..."
- "Which of the following is true about..."

## Core Principle: Paraphrasing

Jawaban yang benar hampir tidak pernah copy-paste dari passage. TOEFL me-restate dengan kata lain.

Contoh: "The vault has a door that weighs more than twenty tons" -> "The entrance to the vault is extremely heavy"

Cocokkan makna, bukan kata.

## Sequential Order Rule

Jawaban detail biasanya muncul berurutan sesuai urutan di teks:
- Soal 1 -> info di kalimat pertama
- Soal 2 -> info di kalimat kedua
- Soal 3 -> info di kalimat ketiga

## Technique

1. Baca soal -> cari keyword (nama, tanggal, istilah teknis)
2. Scan passage -> lokasi keyword
3. Baca kalimat sekitarnya -> pahami konteks
4. Eliminate yang jelas salah
5. Pilih yang maknanya cocok (paraphrase), bukan yang kata-katanya mirip

## Common Detail Traps

| Trap | Contoh | Kenapa salah |
|------|--------|--------------|
| Wrong timing | "during" vs "after" | Passage bilang SETELAH, bukan SELAMA |
| Example = method | U-shaped valleys | Contoh dari 1 metode, bukan metode terpisah |
| Wrong attribution | Track gauge vs standard time | Efek dari A dibilang dari B |
| Opposite | "settled 26 years after" | Kebalikan dari isi passage |
| Different location | Info dari paragraf lain | Fakta bener tapi konteks beda |
| Keyword bait | Kata sama, konteks beda | Ada kata persis sama tapi makna beda |
| "Before" vs "with" | "with each contraction" | "Before" != "with" |

## Worked Examples

### Ice Ages (Q1): Wrong timing
Soal: "What happens during an ice age?"
Trap: (B) Evidence found -> itu SETELAH, bukan SELAMA
Benar: (C) Ice covers large area -> "extensive areas" = "large portion"

### Ice Ages (Q2): Example vs method
Trap: 3 land features -> keliatan 3 metode
Benar: (B) Two -> ketiganya CONTOH dari 1 metode

### Heart (Q5): "Before" vs "with"
Passage: "with each contraction"
Trap: (C) Before each contraction
Benar: (A) As the heart beats -> "with" = "as"

### Railroad (Q9): Wrong date attribution
Standard time = 1883, Track gauge = 1886
Trap: (B) June 1, 1886 -> itu track gauge
Benar: (D) Before standardized track gauge -> 1883 < 1886

### Railroad (Q8): Wrong effect attribution
Trap: (C) Time zones -> itu dari STANDARD TIME
Benar: (B) Improved economy -> dari TRACK GAUGE

## Difference from Gist Questions

| Aspect | Gist (Skill 1) | Detail (Skill 3) |
|--------|----------------|-------------------|
| Focus | Keseluruhan passage | Fakta spesifik |
| Jawaban | Ide berulang | Info tertulis langsung |
| Scope | Semua paragraf | 1 kalimat |
| Trap | Too broad/narrow | Wrong timing/attribution |
| Method | Skim theme | Scan keyword |
