# Sidang/Hasil vs Proposal — Slide Structure Differences

## For Seminar Hasil Skripsi (Final Defense)

Unlike seminar proposal, Seminar Hasil should be **streamlined and concise** — the audience already approved the proposal and now wants to see results.

### Remove these slides:
- **Landasan Teori / Kajian Pustaka** — user feedback: "untuk sidang ga perlu ada teori kali, langsung aja"
- **Penelitian Terdahulu** — belongs in proposal, not defense
- Any redundant theory-heavy slides

### Keep it to 10-12 slides max:
1. Cover
2. Rumusan Masalah
3. Metode Penelitian
4. Prosedur ADDIE (or methodology flow)
5. Hasil RM 1
6. Hasil RM 2
7. Hasil RM 3
8. Simpulan & Rekomendasi
9. Live Demo (if applicable)
10. Terima Kasih

### Time target: ~1 slide per minute (10-15 minute defense)

### Key rule from user: "Itu ngabisin waktu juga"
If the user complains about duration, CUT theory/review slides first, not result slides.
