# TOEFL Listening — Restatement Techniques

## Skill 1: Restatements

### Key Strategies
1. **Focus on the second line** — jawaban benar biasanya ada di kalimat kedua dialog, jangan buru-buru pilih setelah kalimat pertama
2. **Choose answers with synonyms** — restatement = sama arti, beda kata. Cari opsi yang pakai kata sepadan
3. **Avoid similar sounds** — banyak distractor sengaja dibuat mirip bunyinya tapi beda arti

### Sinonim Pairs (Common in Restatement Questions)

| Original | Restatement |
|---|---|
| a little | a bit |
| sick | ill |
| couldn't afford | didn't have enough money |
| called off | cancelled |
| good at picking up | learns quickly |
| look into | investigate |
| matter | issue |
| chef | cook |
| prepared | made |
| meal | food |
| big | large |
| happy | glad |
| fast | quick |
| buy | purchase |
| start | begin |

### Similar Sound Traps (Distractors)

| Word | Sounds Like | Different Meaning |
|---|---|---|
| chef | chief | chef=koki, chief=pemimpin |
| accepted | expected | accepted=menerima, expected=mengharapkan |
| sick | thick | sick=sakit, thick=tebal |
| feet | feel | feet=kaki, feel=merasa |
| deal | meal | deal=kesepakatan, meal=makanan |

### Worked Example

**Dialogue:**
- 👩 (woman): "Steve, is something the matter? You don't look very good."
- 👨 (man): "Oh, I'm feeling a little sick today."
- 🎙️ (narrator): "What does the man mean?"

**Answer choices:**
- (A) He's not very good-looking. ❌ — soal penampilan, bukan kesehatan
- (B) He's a bit ill. ✅ — **a little → a bit**, **sick → ill** (sinonim)
- (C) He looks worse than he feels. ❌ — interpretasi berlebihan
- (D) His feet are a little thick. ❌ — similar sound trap ("feet"≈"feel", "thick"≈"sick")

**Why B is correct:** a little = a bit, sick = ill → same meaning, different words = restatement

### Explanation Style for These Questions
- Break down each answer choice (A/B/C/D)
- Use synonym mapping tables (Original → Restatement)
- Highlight distractor traps explicitly
- Explain in Indonesian, casual style
- Side-by-side comparison: sinonim vs similar sound
