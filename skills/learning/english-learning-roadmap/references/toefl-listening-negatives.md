# TOEFL Listening — Negatives Technique

## Skill 2: Negatives

### Core Rule
Kalau soal pakai kalimat **negatif**, jawaban yang bener biasanya pakai kata **lawan kata** (antonim) atau paraphrase makna negatif.

### Key Strategies
1. **Negatif → Antonim**: "wasn't quiet" = "noisy" (lawan kata)
2. **Negatif → Sinonim/Paraphrase**: "not a lot" = "only a little" (sama arti, beda diksi)
3. **Jangan terkecoh "not" + kata yang mirip bunyi** — fokus ke makna keseluruhan

### Common Negation Patterns

| Pattern | Restatement |
|---|---|
| wasn't quiet | noisy |
| wasn't careful | careless |
| not a lot | only a little |
| couldn't afford | didn't have enough money |
| wasn't happy | sad |
| didn't like | hated |
| doesn't work | broken / out of order |
| won't be ready | still unfinished |
| never arrives | always late / doesn't come |
| no one showed up | the place was empty |

### Antonim Pairs (Common in Negatives Questions)

| Kata | Lawan Kata |
|---|---|
| quiet | noisy |
| careful | careless |
| happy | sad |
| fast | slow |
| hot | cold |
| expensive | cheap |
| crowded | empty |
| easy | difficult |
| cloudy | sunny |
| dark | bright |

### Worked Example 1 — Classic Negatives

**Dialogue:**
- 👩 (woman): "Did you get a lot of work done at the library today?"
- 👨 (man): "I couldn't. It wasn't very **quiet** there."
- 🎙️ (narrator): "What does the man mean?"

**Answer choices:**
- (A) **The library was noisy.** ✅ — wasn't quiet → noisy (negatif + antonim)
- (B) He got a lot done. ❌ — kebalikan, doi bilang ga bisa kerja
- (C) He couldn't quite get to the library today. ❌ — doi udah di sana, cuma ga tenang
- (D) The library's a good place to work because it's quiet. ❌ — kebalikan

**Why A:** wasn't quiet (negatif) = noisy (antonim). Rumus: negatif + lawan kata = jawaban bener.

### Worked Example 2 — Negatives with Paraphrase

**Dialogue:**
- 👩: "You made so many mistakes in this homework."
- 👨: "I wasn't very **careful**."
- 🎙️: "What does the man mean?"

**Answer choices:**
- (A) **He was rather careless.** ✅ — wasn't careful → careless (antonim)
- (B) He does not care about mistakes. ❌ — "careful" ≠ "care about"
- (C) He took care of the work at home. ❌ — "careful" ≠ "took care of"
- (D) He did not carry the work home. ❌ — ngawur, similar sound trap

### Worked Example 3 — Not a Lot

**Dialogue:**
- 👨: "Is there a lot of soup? I'm kind of hungry."
- 👩: "Sorry, there's **not a lot**."
- 🎙️: "What does the woman mean?"

**Answer choices:**
- (A) There's not very much soap. ❌ — "soap" ≠ "soup" (similar sound trap!)
- (B) She doesn't like soup. ❌ — ga ada bilang ga suka
- (C) **There's only a little soup.** ✅ — not a lot = only a little
- (D) The man should not be hungry. ❌ — ga relevan

### Worked Example 4 — Figurative Negatives

**Dialogue:**
- 👩: "How was the weather on your trip?"
- 👨: "There **wasn't a cloud** in the sky."
- 🎙️: "What does the man mean?"

**Answer choices:**
- (A) It was cloudy. ❌ — kebalikan! wasn't cloud = cerah
- (B) He couldn't see the sky. ❌ — ngawur
- (C) It wasn't very crowded. ❌ — **similar sound trap!** "cloud" ≠ "crowded"
- (D) **There was a lot of sunshine.** ✅ — wasn't a cloud = cerah = banyak sinar matahari

### Pitfalls
- ❌ Jangan pilih jawaban yang mengulang kata negatif tanpa mengubah makna
- ❌ "not quiet" ≠ "not loud" — fokus ke antonim langsung (noisy)
- ❌ Watch out for similar sounds: cloud/crowded, soap/soup, feet/feel
- ✅ Selalu tanya: "apa arti POSITIF dari kalimat negatif ini?"

### Quick Formula
```
Negatif + Antonim = Jawaban Benar ✅
wasn't quiet → noisy
wasn't careful → careless
not a lot → only a little
wasn't a cloud → sunny/clear
```
