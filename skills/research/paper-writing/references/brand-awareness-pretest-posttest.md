# Brand Awareness + One-Group Pretest-Posttest Notes

Use this note when a skripsi/proposal asks whether website research should be framed as *efektivitas* or *pengaruh*, especially for a one-group pretest-posttest design.

## Core decision rule
- If the study uses **one group measured before and after treatment** without a control group, frame the claim as **effectiveness / improvement after intervention** more safely than a strong causal **influence/effect** claim.
- Reason: the design can show change from pretest to posttest, but causal attribution is limited by internal-validity threats.

## Design interpretation
- One-group pretest-posttest is appropriate for measuring **perubahan sebelum–sesudah** after an intervention.
- It is weaker for strong causal language because there is no control group.
- Typical internal-validity caveats: history, maturation, testing effects, instrumentation, regression to the mean.

## Statistical test selection
1. Check normality of paired differences / scores.
2. If normal: use **Paired Sample T-Test**.
3. If not normal: use **Wilcoxon Signed Rank Test**.
4. Descriptive support can include **gain score** and **percentage increase**, but these do not replace inferential testing.

## Variable logic for this class of thesis
- **Outcome variable:** *brand awareness*
- **Recommended indicators:**
  - *brand recognition*
  - *brand recall*
  - *top of mind*
- *unaware of brand* can be discussed conceptually as the lowest awareness level, but does not have to be a separate questionnaire indicator.

## Writing guidance for BAB II / BAB III
- If using **effectiveness**, add a BAB II subsection such as: *Efektivitas Website terhadap Peningkatan Brand Awareness*.
- Distinguish clearly between:
  - **indikator konstruk** (what brand awareness consists of), and
  - **indikator efektivitas hasil** (how improvement is evaluated: pretest, posttest, gain, %, significance).
- Align wording across:
  - rumusan masalah
  - tujuan penelitian
  - hipotesis
  - teknik analisis data

## Suggested wording pattern
- Rumusan masalah: *Apakah website X efektif dalam meningkatkan brand awareness?*
- Tujuan: *Mengetahui efektivitas website X dalam meningkatkan brand awareness.*

## Pitfall
Do not keep the word *pengaruh* just because it sounds stronger if the actual design is only one-group pretest-posttest. Either strengthen the design or soften the claim to effectiveness/improvement.

## Versi Siswa vs Versi Masyarakat — Key Differences

When the research population is **siswa kelas XI** (not masyarakat), the framing shifts from marketing effectiveness to **learning effectiveness**. Key differences:

| Aspect | Versi Masyarakat | Versi Siswa |
|--------|-----------------|-------------|
| Rumusan masalah | Efektivitas website meningkatkan brand awareness di kalangan masyarakat | Efektivitas website sebagai media pembelajaran brand awareness bagi siswa |
| BAB 2 theory | Marketing, digital marketing, brand awareness | + Media pembelajaran, efektivitas pembelajaran |
| Instrumen | Brand awareness survey (masyarakat) | Pre-test/post-test pemahaman brand awareness (siswa) |
| Analisis | Gain score + % peningkatan + paired t-test/Wilcoxon | Same, but framed as learning outcome |
| Kriteria efektivitas | Mahmudi (2015) % categories | Same Mahmudi table, but interpreted as learning gain |
